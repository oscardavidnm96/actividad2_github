# Guía de Introducción a Git y GitHub

## 1. ¿Qué es Git?
Git es un sistema de control de versiones de código abierto. Sirve para registrar los cambios que realizamos en los archivos de un proyecto a lo largo del tiempo, permitiéndonos volver a versiones anteriores, trabajar en diferentes ramas de desarrollo y mantener un historial completo de todo lo que se ha modificado.

## 2. ¿Qué es GitHub?
GitHub es una plataforma de alojamiento en la nube que permite guardar repositorios de Git de forma remota. Además de servir como copia de seguridad de nuestros proyectos, ofrece una interfaz web y herramientas para facilitar el trabajo colaborativo entre desarrolladores, gestionar problemas (issues) y publicar código.

## 3. Diferencia entre Repositorio Local y Repositorio Remoto
* **Repositorio Local:** Es el que se encuentra guardado físicamente dentro de tu propio ordenador. Trabajas en él sin necesidad de tener conexión a internet, realizando confirmaciones de tus cambios (commits) de manera interna.
* **Repositorio Remoto:** Es el que está alojado en un servidor de internet (en este caso, en los servidores de GitHub). Sirve para publicar tu código en la red, compartirlo con otros desarrolladores y sincronizar los cambios que subes desde tu repositorio local.
